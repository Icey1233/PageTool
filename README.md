# 登录工作台

本地网站入口：

```text
http://127.0.0.1:8017/password-workspace.html
```

文件：

```text
password-workspace.html
start-password-workspace.ps1
```

## 启动方式

在 Windows PowerShell 里运行：

```powershell
.\start-password-workspace.ps1
```

脚本会在本机 `127.0.0.1:8017` 启动静态服务并打开浏览器。

## 已有功能

- 用主密码解锁
- 网站账号、密码、标签、备注集中管理
- 网站列表显示网页图标
- 搜索网站、网址、账号、标签、备注
- 一键打开网站
- 一键复制账号或密码
- “登录”按钮会打开网站并复制账号
- 新建工作区，把一次任务用到的多个网站组合起来
- 全部网站按工作区分组显示，未归类的网站会放在默认工作区
- 网站可拖到不同工作区，并选择移动或复制；同一个网站可存在于多个工作区
- 可把其它页面或地址栏里的网址拖入工作台自动创建网站
- 新建或编辑网站时可直接勾选要加入的工作区
- 一键打开当前工作区
- 编辑当前工作区
- 导出/导入加密备份
- GitHub Gist 加密同步
- 修改后 15 秒自动上传同步，可在倒计时里取消
- 显示/隐藏密码
- 生成强密码
- 清空剪贴板
- 自动锁定

## 安全说明

- 数据保存在当前浏览器的 `localStorage`。
- 保存内容会用主密码派生密钥后通过 `AES-GCM` 加密。
- 主密码不会保存。忘记主密码后无法解密已有数据。
- 导出的备份仍然是加密内容，需要原主密码解锁。
- GitHub Gist 同步只上传加密后的密文。只需要填写 Token；Gist 会自动查找或创建，相关同步信息会写入加密密码库，之后输入同一个主密码会自动回填。
- Fine-grained token 需要在 `Account permissions` 里把 `Gists` 设为 `Read and write`；classic token 需要勾选 `gist`。
- 首次配置前，GitHub Token 会临时保存在当前浏览器本地；建议只给它 Gist 同步需要的最小权限。
- 使用公共电脑时，使用后请锁定并清空剪贴板。

## 快速登录边界

当前网页版本支持：

- 打开登录页
- 复制账号
- 复制密码

普通网页不能可靠地给第三方网站自动填充账号密码，也不能稳定点击登录按钮。要实现自动填充，需要升级为 Chrome/Edge 浏览器扩展。
